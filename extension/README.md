# Team Pico Chat

Pico는 VS Code에서 열린 프로젝트의 코드를 설명하고, 수정안을 만들고, 오류 원인을 찾는 채팅 에이전트입니다. **VS Code 1.106 이상**에서 사용할 수 있습니다.

## 채팅 시작하기

1. VS Code에서 작업할 프로젝트 폴더를 엽니다. 여러 폴더를 열었다면 Pico는 첫 번째 워크스페이스 폴더를 사용합니다.
2. 오른쪽 보조 사이드바에서 **Pico**를 엽니다. 명령 팔레트에서 **Open Pico Chat**을 실행하거나 macOS에서는 **⌘ Esc**, Windows와 Linux에서는 **Ctrl+Esc**를 눌러도 됩니다.
3. 채팅 상단에 **연결됨**이 표시되면 모델을 확인합니다. 설정 안내가 뜨면 **OpenAI API 키 연결**을 선택하거나, 사용할 수 있는 서버 기본 모델이 표시될 때 **현재 모델로 계속**을 선택합니다. 모델 이름을 눌러 사용 가능한 모델을 바꿀 수 있습니다.
4. 메시지를 입력하고 **Enter**를 누릅니다. 예를 들어 “로그인 흐름을 설명하고 관련 파일을 알려줘” 또는 “이 테스트가 실패하는 원인을 찾아줘”라고 요청할 수 있습니다.

## 채팅 중에 할 수 있는 일

- **Shift+Enter**로 줄바꿈하고, 답변이나 작업이 진행 중일 때 채팅에 포커스를 둔 채 **Esc**를 눌러 중지할 수 있습니다.
- Pico가 도구 실행 권한을 요청하면 내용을 확인한 뒤 **이번만 허용** 또는 **거절**을 선택하고 **응답 보내기**를 누릅니다.
- 추가 질문이 나타나면 답변을 선택하거나 입력한 뒤 **응답 보내기**를 누릅니다. 응답을 생략하려면 **건너뛰기**를 누릅니다.

## 연결이 안 될 때

- **연결 오류**가 뜨면 채팅 상단의 **다시 연결** 버튼을 누릅니다. 자동 연결에 필요한 CLI를 다운로드할 수 없는 경우, 설치된 호환 CLI의 실행 파일 경로를 VS Code 설정의 `opencode.cliPath`에 지정할 수 있습니다.
- 이미 실행 중인 호환 서버가 있다면 채팅 상단의 **서버 주소 설정**에서 주소를 입력하세요. **인증 필요**가 표시되면 **비밀번호 입력** 버튼을 사용하세요.
- 서버에는 연결됐지만 메시지를 보낼 수 없다면, 채팅 상단에서 사용할 모델을 선택하거나 OpenAI API 키를 연결하세요.

## 라이선스
